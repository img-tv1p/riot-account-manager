# Riot Account Manager (RAM)

Легковесный и безопасный менеджер аккаунтов Riot Games и автоматический граббер кодов двухфакторной аутентификации (2FA) для Windows.

Приложение работает в фоновом режиме в системном трее, перехватывает входящие письма с кодами авторизации от Riot Games, мгновенно копирует код в буфер обмена и отправляет нативное уведомление Windows. Также позволяет сохранять несколько учетных записей и осуществлять автоматический вход в Riot Client в один клик.

---

> [!IMPORTANT]
> **Информация о совместимости:**
> Программа разрабатывалась и тестировалась **исключительно на Windows 11** с использованием почтового сервиса **Яндекс Почта**. 
> Работа на других версиях операционной системы или с другими почтовыми провайдерами может содержать непредвиденные ошибки. Если вы столкнулись с проблемой — пожалуйста, создайте обращение в разделе [Issues](../../issues).

## Безопасность и конфиденциальность

Все ваши данные остаются исключительно под вашим контролем. Приложение не имеет собственных внешних серверов, аналитики или телеметрии.

* **Хранение только на вашем ПК:** Никакие логины, пароли, почтовые адреса или коды не передаются третьим лицам и не покидают пределы вашего компьютера. Все сетевые взаимодействия происходят напрямую между вашим компьютером и официальным IMAP-сервером вашей почты по защищенному SSL/TLS протоколу.
* **Аппаратное шифрование Windows DPAPI:** Все конфиденциальные данные (пароли от аккаунтов Riot и пароли приложений почты) шифруются системным криптографическим механизмом Windows Data Protection API (`CryptProtectData`). Расшифровать эти данные возможно исключительно под вашей учетной записью Windows на вашем физическом компьютере.
* **Открытый исходный код:** Проект полностью прозрачен — вы можете лично проверить исходный код каждого модуля приложения перед запуском.

## Возможности приложения

* **Моментальный перехват кодов 2FA:** При получении письма от Riot Games код авторизации моментально извлекается, копируется в буфер обмена и выводится через нативное уведомление со звуком. Больше не нужно переключаться в браузер и вручную открывать почту.
* **Менеджер аккаунтов:** Удобный графический интерфейс со списком всех ваших аккаунтов. Поддерживается добавление, редактирование, удаление и быстрый выбор активного профиля.
* **Автоматический вход в Riot Client в один клик:** При нажатии на кнопку входа приложение самостоятельно активирует окно Riot Client и вводит логин и пароль в нужные поля.
* **Индивидуальная привязка почтовых ящиков:** К каждому аккаунту Riot можно привязать как собственный почтовый ящик, так и использовать один общий для нескольких записей.
* **Функция FIX VAL43:** Встроенный инструмент решения частой ошибки Riot Client (код ошибки VAL 43). Корректно завершает зависшие процессы Riot Client и Valorant, удаляет поврежденные кэш-файлы активной сессии и перезапускает клиент в чистом виде.
* **Быстрый выход из аккаунта (Logout):** Безопасный сброс авторизации клиента для возврата на стартовый экран входа без необходимости перезагрузки ПК.
* **Компактная работа в системном трее:** При закрытии окна интерфейс сворачивается в трей, освобождая ресурсы. Вызов меню осуществляется в один клик по иконке в трее.
* **Автозагрузка:** Возможность запуска программы вместе со стартом Windows одним переключателем в меню.

## Преимущества

* **Нулевая нагрузка на систему:** В режиме ожидания приложение не нагружает процессор (0% CPU), используя сокетное ожидание входящих сообщений.
* **Удобство ввода:** Полноценная поддержка буфера обмена (Ctrl+C, Ctrl+V, Ctrl+A) независимо от активной раскладки клавиатуры (RU / EN), а также контекстное меню правой кнопки мыши во всех полях ввода.
* **Автономность:** Программа не требует сторонних вспомогательных утилит.

## Гайд по привязке почты к приложению

Для того чтобы приложение могло автоматически считывать коды авторизации, ему требуется доступ к почтовому ящику по безопасному протоколу IMAP. 

> [!WARNING]
> Никогда не используйте основной пароль от вашего почтового ящика. Для почтовых клиентов используется специальный **Пароль приложения** — защищенный одноразовый ключ доступа, генерируемый в настройках безопасности почтового сервиса.

### Настройка Яндекс Почты (Рекомендуемый метод)

1. Перейдите на страницу создания паролей: [Яндекс ID — Пароли приложений](https://id.yandex.ru/security/app-passwords).
2. Нажмите **Создать пароль приложения**.
3. Выберите тип приложения: **Почта**.
4. Укажите название (например, `RAM` или `Riot Manager`) и нажмите кнопку создания.
5. Скопируйте сгенерированный 16-значный пароль приложения (он отображается один раз).
6. Откройте настройки [Яндекс Почты](https://mail.yandex.ru) (кнопка шестеренки в правом верхнем углу → *Все настройки* → *Почтовые программы*).
7. Убедитесь, что отмечена галочка **С сервера по протоколу IMAP** (по умолчанию обычно включена).
8. В приложении RAM введите ваш адрес почты и полученный 16-значный пароль приложения.
9. Нажмите кнопку проверки подключения для сохранения.

### Настройка Mail.ru

1. Перейдите в раздел безопасности: [Mail.ru — Пароли для внешних приложений](https://account.mail.ru/user/2-step-auth/passwords).
2. Нажмите **Добавить пароль**, укажите имя приложения и подтвердите создание.
3. Скопируйте созданный пароль и укажите его в окне настройки RAM.
4. Доступ по протоколу IMAP в Mail.ru активен по умолчанию.

### Настройка Gmail

1. Убедитесь, что в аккаунте Google включена двухэтапная аутентификация.
2. Перейдите на страницу: [Google — Пароли приложений](https://myaccount.google.com/apppasswords).
3. Создайте новый пароль приложения и скопируйте полученную комбинацию из 16 символов.
4. В настройках Gmail (*Все настройки* → *Пересылка и POP/IMAP*) убедитесь, что включен статус **Включить IMAP**.
5. Укажите почту и созданный пароль в приложении RAM.

## Запуск и использование

### Готовый бинарный файл

1. Скачайте актуальный исполняемый файл `RAM.exe` из раздела [Releases](../../releases).
2. Запустите файл. При первом старте программа автоматически установит себя в каталог `C:\Program Files (x86)\RAM`, создаст ярлык `Riot Account Manager - RAM` на Рабочем столе и откроет мастер первоначальной настройки.
3. После завершения настройки приложение работает в системном трее (возле часов Windows).

### Запуск из исходного кода

Требуется установленный Python 3.10+ (рекомендуется Python 3.12).

1. Клонируйте репозиторий:
```bash
git clone https://github.com/img-tv1p/riot-account-manager.git
cd riot-account-manager
```

2. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

*(Или установите вручную: `pystray`, `Pillow`, `winotify`, `pywin32`)*

3. Запустите приложение:
```bash
python main.py
```

## Структура репозитория

* `main.py` — Точка входа в приложение.
* `tray_app.py` — Координатор системного трея, фоновые слушатели и диспетчер окон.
* `gui_menu.py` — Главное графическое окно управления аккаунтами и настройками.
* `first_run_wizard.py` — Пошаговый мастер первой настройки при первом запуске.
* `email_setup_dialog.py` — Окно редактирования и интерактивной проверки почтовых ящиков.
* `account_manager.py` — Менеджер хранения и валидации аккаунтов.
* `crypto_manager.py` — Модуль локального шифрования учетных данных через Windows DPAPI.
* `imap_listener.py` — Фоновый клиент IMAP IDLE для мгновенного отслеживания входящих писем.
* `email_parser.py` — Анализатор писем от Riot Games и извлечение кодов подтверждения.
* `riot_automator.py` — Автоматизация заполнения данных в интерфейсе Riot Client.
* `val43_fixer.py` — Модуль сброса сессий и устранения ошибки VAL 43.
* `app_installer.py` — Менеджер локальной установки, создания ярлыков и автозагрузки Windows.
* `gui_clipboard_helper.py` — Поддержка клавиатурных комбинаций и контекстного меню буфера обмена.
